# 更新记录

## 0.4.1（2026-10-14）

- 修复每 2 秒刷新重建菜单，导致「详细信息」「历史用量」子菜单闪烁的问题。
- 菜单展开时原位更新数字和文字，保留所有菜单项及子菜单；增删条目延后至下次打开。
- 设备读取失败立即清空失效数字，恢复后继续更新；切换网络时关闭旧菜单。
- 增加原生 AppKit 回归，验证连续 100 次刷新、读取失败与恢复、跨日及设备列表变化时对象保持稳定。

## 0.4.0（2026-10-14）

- 主菜单按实时速率、当前网络、F50 Pro 专属板块和历史用量组织。
- 当前网络确认为 F50 Pro 才显示专属板块；其他网络隐藏整块及其探测、错误和配额提示。
- 按网关 MAC 留存设备型号确认，临时读取失败保留板块并清空旧数字；相同网关 IP 或用户网络名称不视为设备身份证明。
- 原始计数、WAN IP、网关及接入设备地址收进「详细信息」，近七天及各网络累计收进「历史用量」。
- 缺少接入设备列表时显示未知，不显示零台；保留套餐配置、校准基准、已有累计和日记录。
- 提取可离线验证的菜单内容，覆盖切网、迟到响应、读取失败、恢复、身份留存和菜单层级。

## 0.3.1（2026-10-14）

- 删除「也可能在月内清零」提示，区分「路由器流量统计」和「SIM 卡月度用量（估算）」。
- 明确 SIM 卡套餐额度由用户手动设置，不表示路由器自带套餐，也不表示已查询运营商账户。
- 仅调整文案，保留既有套餐配置、校准用量和统计记录。

## 0.3.0（2026-10-14）

- 修正将设备 `monthly` 字段直接视为完整套餐月度用量的问题，显示为「设备当前计数」。
- 新增套餐重置日、时区和运营商已用量校准，显示明确起止日期；默认不猜重置日。
- 保存独立月度累计和计数基线，重启不重复累计，设备清零保留本月记录，跨月保留历史周期。
- 初始用量未知或采样存在不确定缺口时，暂停百分比、余量和提醒，提示校准。
- 提醒按套餐周期保存，同周期设备清零或校准不重复发送。
- 保留既有本机累计、每日记录、旧提醒记录与配置扩展字段。

## 0.2.1（2026-10-13）

- 同一台 F50 Pro 的升级前后累计合并为一条记录，界面统一显示「F50 Pro」。
- 保留上传、下载总数、最早统计时间及已有日记录，合并前独立备份。
- 加载时可根据已确认设备记录合并，不要求当前连着 F50；重复启动不会重复累加。
- 多台已确认 F50 时不猜归属；不影响其他网络，也不补造缺失日明细。

## 0.2.0（2026-10-13）

- 修复切网、换网卡误记，以及失败读数恢复后的重复累计。
- 原生网络识别与后台计数读取，避免阻塞菜单。
- 路由器状态统一在主线程更新，绑定网络和请求序号，切网清空快照。
- 正确处理零用量、缺失字段、其他型号与 HTTP 失败。
- 每 30 秒原子保存，保留有效备份，支持损坏文件恢复。
- 保留原配置与扩展字段，校验范围并重建刷新 Timer。
- 新增设置、网络命名、本次连接时长、更新时间、近七天本机用量和可选额度提醒。
- 使用「路由器本周期用量」与「估算剩余」，说明运营商查询边界。
- 显式指定 macOS 12 部署目标；正常退出不自动拉起，阻止重复实例写数据。
- CSV 脚本移除 `eval`、密码与 Cookie 登录，修复采样时钟与跨网络窗口。
- 增加离线回归检查，保留旧版累计与升级前 App。
