# 0.7.0 本机月度用量验证

日期：2026-10-15。环境：Apple Silicon、macOS 27，macOS 12 部署目标。

## 实现

原生菜单卡片内的七天柱图改为当月方块图，每天一个方块，按月历生成 28–31 天。月度汇总跨全部网络，上传与下载相加，区分本机经过已确认 F50 Pro 的流量与其他网络流量。设备整体计数、运营商校准值不参与本机月度图。

有 F50 Pro 用量时使用强调色；已记录但无 F50 Pro 用量（含真实零值）使用灰色；未记录使用空心，未来日期使用更淡的空心。悬停更新图下方明细，未来和未记录日期不显示虚构的零。两行日期方块之间的间隙不选中日期，离开后显示当天明细。

F50 Pro 历史网络归属单独保存为 `f50Networks`，旧记录从已经验证的设备型号与网关 MAC 补齐；当前设备识别信息移除后仍保留历史归属。网络别名不能用于型号证明。旧每日明细、网络累计和套餐记录继续保留，没有历史保留期裁剪。

## 已完成验证

- 152 项 Swift 数据回归、118 项原生菜单回归、247 项卡片回归和 10 项脚本检查通过。
- 渲染模式共 542 项检查通过，实际进入 NSMenu 跟踪循环，取得 NSPopupMenuWindow 渲染；测试菜单高度 723 pt，卡片 582 pt，没有内部滚动容器。
- 混合网络样本验证每日总量、其中 F50 Pro、其他网络与月度总量一致；不把设备整体流量或套餐校准基线混入本机计数。
- 覆盖大小月、闰年二月、跨年、相邻月份排除、未来记录排除、真实零值和缺失日期。
- 覆盖旧状态读取、历史归属序列化、当前型号证明移除、用户别名不能制造 F50 Pro 归属、非法历史网络身份拒绝加载。
- 连续 100 次刷新复用菜单行和承载视图、保持打开时的行高与日期选择；切换网络保留跨网络月度浏览。
- 渲染覆盖明暗主题、设备读取失败、其他网络、F50 Pro 和灰色日期明细、二月份切换以及实际原生菜单。逐一检查每个方块的原生坐标命中；月份变化后不会残留旧日期悬停区域。
- 优化构建及严格签名检查通过。
- 已安装 0.7.0，当前真实 F50 Pro 只读诊断通过；运行时版本、原生菜单样式与单实例检查通过。
- 对照安装程序正常停止旧版后保存的备份，原有 13 条网络累计、日记录和套餐记录均保留；历史日期数值不变，配置文件、校准时间、校准起点、质量标记及提醒记录不变。
- 真实保存数据的月度总量、F50 Pro 用量、其他网络用量及已记录天数，与独立 Python 汇总逐项相同。

本地证据位于忽略目录 `build/tests/v070-test.log`、`v070-render.log`、`v070-build.log` 、`v070-runtime-acceptance.json`、`v070-month-snapshot.json` 和 `native-card/`。渲染使用离线样本，图中用量不代表当前运营商余额。

## 边界

只覆盖 App 运行且本机采样有效的用量，不补齐程序开始记录前或未采样时段的数据。历史网络识别仍受已有网关身份能力约束，无法仅靠网络别名补回从未验证过的设备归属。没有开发月份切换入口或独立统计页。设备整体计数、每设备用量能力和套餐断采判断不在本次修改范围。

本次确认了原生菜单渲染与坐标命中，没有将测试视图的直接调用视为真实鼠标事件端到端验收。旧 macOS、Intel 和其他设备固件仍需实机验证。
