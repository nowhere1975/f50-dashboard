# 0.8.0 改名、适配模块与当天标识验证

日期：2026-10-15。环境：Apple Silicon、macOS 27，macOS 12 部署目标。

## 实现

应用显示名称统一为 Traffic Monitor，内部可执行文件、Bundle ID、开机启动标识和数据目录沿用原值。当天方块使用静态主题色微光，悬停光晕略增强，移除黑色选中边框；悬停明细不改变菜单尺寸。

路由器型号识别和接口解析从主程序拆出，F50 Pro 的 WebUI 协议集中在 `F50ProAdapter.swift`。通用模块契约提供稳定 ID、型号匹配、能力、计数规则、请求、异步准备及标准化读数；传输层统一处理自动识别、显式选择、准备与数据请求的取消。主程序继续负责网络身份、过期响应拒绝、套餐累计、历史保存和菜单。

设置支持自动识别、只使用本机监控或指定模块。当前发布版本仅内置 F50 Pro 模块。Fixture 模块和异步准备模块仅用于测试，不构成对其他实际路由器的支持；本版没有第三方插件热加载。

## 已完成检查

- 152 项 Swift 数据回归、42 项模块契约与传输检查、118 项原生菜单检查、248 项卡片检查及 10 项脚本检查通过。
- 模块检查使用独立的第二模块及受控 URLProtocol 响应，验证按序识别、已知模块优先、显式选择、关闭读取时无网络请求、能力过滤、准备请求头、取消准备及在途请求不会产生迟到结果。
- 第二模块经过主程序的设备状态、套餐累计、月度历史、详情和能力显示；没有加入任何 F50 型号分支。移除模块后仍可读取已有历史。
- 旧设置缺少模块字段时使用自动识别；旧设备与历史归属补齐通用模块记录；套餐来源变化不把两种原始计数直接相减。
- 原生渲染模式共 789 项检查通过，取得实际 NSPopupMenuWindow 渲染，人工检查标题、无黑边和当天微光。测试卡片 478 pt，菜单 619 pt，无内部滚动容器。
- 生产 AppDelegate 集成检查通过，含 100 次刷新保持菜单对象、读取失败清空旧数字、切网、根菜单关闭清除悬停及只用本机时仍保留历史入口。
- 实际创建设置窗口，检查 Traffic Monitor 标题、三个模块选项、默认选中值和保存按钮在可视范围内。
- 优化构建及严格签名检查通过；安装文件与最终构建的 SHA-256 一致，显示名称为 Traffic Monitor，内部 Bundle ID 不变。
- 实际 F50 Pro B27 只读诊断通过，运行快照确认 0.8.0、`zte.f50pro` 模块就绪、套餐估算可用且只有一个主实例；版本与模块列表命令正常。
- 对照从 0.7.1 正常停止后保存的首份升级备份，13 条累计、日记录和套餐记录均保留，历史日期数值不变；配置、校准时间与起点、质量标记、计数清零次数及提醒记录不变，设备增量接续无重复。
- 用独立 Python 汇总实际保存的每日记录，与新版 Swift 月度模型逐项比较，总量、路由器、其他网络和已记录天数一致。

本地证据位于忽略目录 `build/tests/v080-test.log`、`v080-render.log`、`v080-integration.log`、`v080-runtime-acceptance.json`、`v080-month-snapshot.json` 和 `native-card/`。界面测试使用离线用量，不表示运营商当前余额。

## 边界

只对已测 F50 Pro B27 提供实机支持；其他型号需要实现模块并验证后随应用重新发布。异步准备测试不代表已经适配任何其他设备的真实登录协议。F50 Pro 的计数清零和断采规则保持原样，不因架构调整就忽略不完整采样。未进行真实鼠标端到端验收，Intel、旧 macOS、其他固件及通知送达仍需实机验证。
