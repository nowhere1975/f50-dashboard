# 当前实现与验证范围

版本：0.7.1。本文对应当前代码，旧版记录可从 Git 历史查阅。

## 结构

| 文件 | 职责 |
|---|---|
| `AppDelegate.swift` | 主线程协调采样、菜单、通知与保存，串行后台线程读取接口计数 |
| `MenuRenderer.swift` | 菜单展开时原位更新文字，保留子菜单对象，增删条目推迟到下次打开 |
| `DashboardSnapshot.swift` | 卡片只读模型、可信余量、跨网络月度用量汇总 |
| `DashboardCard.swift` | 原生菜单内的透明 SwiftUI 卡片、行高测量和月度方块悬停 |
| `DashboardMenu.swift` | 菜单内容、F50 Pro 条件显示、详细信息与历史子菜单 |
| `TrafficTracker.swift` | 分桶、采样基线、每日用量和提醒记录 |
| `BillingCycle.swift` | 明确月度边界、设备增量接续、运营商校准和周期内提醒 |
| `StateStore.swift` | 原子保存、有效备份、损坏文件留存与恢复 |
| `RouterClient.swift` | 只读请求、HTTP 状态、型号与字段解析 |
| `RouterState.swift` | 请求序号与网络绑定、设备身份和板块状态，拒绝过期响应 |
| `SysInfo.swift` / `NetworkObserver.swift` | 原生网络状态、系统变更通知、接口计数读取 |
| `Config.swift` / `SettingsController.swift` | 配置校验与设置 |
| `main.swift` | 启动与诊断 |

URLSession 与后台采样的结果先切回主线程，再更新状态。采样结果还需通过网络上下文和世代检查。文件锁阻止多个实例写累计。

## 采样与存储约束

1. 网卡、网关、DNS 或 MAC 变化时重建基线。
2. 失败用 `nil` 表示，零计数有效。
3. 单调递增且间隔正常的连续帧才累计，不回填不确定窗口。
4. 路由器快照绑定网络与请求序号；切网清空快照，拒绝旧响应。
5. 型号需确认 F50；完整有效的设备计数只用于当前读数和已配置周期的增量记录，不直接作为套餐月度总数。
6. 本次连接时间与桶首次记录时间分别显示。
7. 有唯一已确认 F50 网络时，升级前后累计合并到同一网络，保留总数与最早时间；多台 F50 不猜归属。合并前独立备份，不制造每日历史。
8. 配置错误保留原文件和当前有效配置，首次启动无有效配置时暂停估算。
9. 每 30 秒原子保存，备份来自上一份有效数据。
10. 损坏文件留存成功后才允许覆盖；留存失败则停止覆盖。
11. 套餐周期默认未配置；只有已知初始用量且无不确定缺口时才估算百分比、余量并提醒。清零保留月度累计，断采或字段变化后提示校准。
12. 月度记录按设备 MAC、重置日、时区和周期起点分别保存；更改周期不删除旧记录，也不把本机历史当成所有设备的套餐月度用量。
13. 专属板块只接受当前网关的 F50 Pro 型号证明；设备 MAC 绑定确认记录，网络别名不能决定板块显示。未确认网络和其他设备不显示探测、失败或配额占位行。
14. 同一已确认设备临时读取失败时保留板块但清空实时数据；同网关 IP、不同 MAC 的其他网络不继承身份或旧余量。

15. 展开菜单期间复用全部菜单项和子菜单，只更新文字；增删结构在下次打开时应用。读取失败立即清空失效数字，切网关闭旧网络菜单。

16. 菜单内卡片复用状态与承载视图，展开期间保持行高；详情与历史使用原生子菜单，没有内部滚动区。切网关闭旧菜单；月度图保留当前月份日期选择，跨月时清空旧日期选择。

## 验证

~~~bash
./build.sh test
./build.sh build
./build.sh check
~~~

Swift 检查覆盖切网、换网卡、失败读数、重置、长间隔、零值、字段缺失、型号、过期响应、配置与备份恢复，以及套餐重置日、短月份、闰年、跨年、时区、校准、重启接续和提醒边界。脚本检查覆盖采样时钟、暂停、文本不执行、切网基线与报告窗口。

构建与回归检查均使用优化模式。接口读数还需与 `netstat -ib` 在同一窗口交叉验证；App 采用后台调用已验证系统工具的读数。

## 验证边界

- 实际设备仅一台 F50 Pro、一个固件版本。
- 本机运行环境为 Apple Silicon / macOS 27；macOS 12 是部署目标，旧系统需实机验证。
- 本机 CLT 缺少 Intel 兼容库，Intel 交叉构建未完成。
- MAC 不可用时按网卡、网关和 DNS 兜底，地址相同的网络可能合并。
- 每日用量只覆盖 App 运行时的有效采样，不等于运营商账单。
- 通知需用户开启并允许；拒绝权限时显示提示。
- 写入失败影响保存时效，错误提示不等于保存成功。

## 0.7.0 本机月度图

当月按实际天数展示方块，汇总所有网络的本机上传、下载量，并通过已验证的网关 MAC 区分 F50 Pro 与其他网络。历史归属独立保存，旧数据从已有型号确认信息补齐。未记录、真实零值与未来日期分别处理；有 F50 Pro 用量的日期悬停展示本机总量及其中 F50 Pro 用量。图表不使用设备整体计数或运营商校准值，不补齐采集开始前的数据，不删除旧日记录。

## 0.7.1 界面精简

套餐卡片移除常驻校准提示、周期起止日期和运营商余量说明，用量标为「本月用量」。月度图移除固定日期明细和采样天数说明，悬停方块时在图上方浮出明细，移开后隐藏；浮层不参与布局，不改变菜单高度。套餐质量判断仍生效，不因移除说明就强行计算不可靠的余量。
