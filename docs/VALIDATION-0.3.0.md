# 0.3.0 月度周期验证

日期：2026-10-14。环境：Apple Silicon、macOS 27、F50ProV1.0.0B27 / MU3356V1.0.0B27。

## 问题与修正

旧版没有配置套餐起止日，直接将设备 `flux_monthly_*` 计数除以额度。设备 WebUI 的只读接口返回自动清零开关 `on`、日期 `1`，但历史采样也存在月内 GB 级降至 MB 级，以及短间隔再次下降的记录，具体原因未确认。因此设备当前计数无法证明完整的套餐月度消耗。

新版分别显示设备计数和套餐月度记录。套餐按明确重置日、时区计算；运营商已用量校准后接续设备增量。清零不删除月度累计，可能漏记时暂停百分比、余量和提醒，提示校准。

## 验证结果

- `./build.sh test`：113 项 Swift、10 项脚本检查通过。
- `./build.sh build`：arm64、macOS 12 部署目标构建通过，签名验证通过。
- `./build.sh install`：安装并启动 0.3.0，保留旧 App、配置和状态的升级备份。
- 设置窗口：独立 AppKit 渲染并检查布局，套餐额度、重置日和校准输入可见，保存按钮在内容区域内；未将此检查视为完整菜单点击验收。
- 真实设备 `--check`：200 GB、每月 1 日、Asia/Shanghai，周期显示为 `2026-10-01 至 2026-10-31`。
- 以剩余 173.93 GB 校准：月度初始已用 26.07 GB，比例 13.04%；当时设备计数约 95.7 MB，与套餐累计分别保存。
- 校准前独立留存原配置和状态至本地 `calibrations/`；旧累计、最早统计时间、网络标签、所有既有每日记录均保留。
- 正常停止并重新启动后核对新进程和新的采样时间：校准时间保留，月度增加值严格等于上传、下载计数增量，没有重新累加设备旧计数，单实例运行，运行提示与日志均无错误。

本地验收快照位于 `build/tests/monthly-acceptance.json`，不提交个人运行数据。

## 回归边界

覆盖重置日、短月、闰年、跨年、时区、零用量、初始用量未知、字段来源变化、单边清零、长间隔、跨月保留、磁盘重载、溢出、无效配置和同周期提醒不重复。

月度余量仍为校准后的估算，采样间的清零可能漏记。新月份初始用量未知时也需要校准；不把本机历史或 CSV 峰值补成整月全部设备的用量。真实运营商账单、通知送达、其他固件、Intel 和旧 macOS 实机仍未验证。
