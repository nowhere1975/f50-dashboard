# 0.5.0 紧凑卡片验证

日期：2026-10-14。环境：Apple Silicon、macOS 27。

## 实现

左键菜单栏打开原生 NSPopover / SwiftUI 紧凑卡片，右键保留文字菜单。主面板提供实时速率、当前网络、F50 Pro 专属的 SIM 卡套餐余量进度条，以及近七天本机用量柱图；设备详情和各网络历史可展开查看。系统主、次级文字色适配明暗主题，柱图与进度条使用随主题调整的青色，关键数字保留清晰对比。

卡片只读模型从现有 TrafficTracker、RouterState 和 Config 构建，不参与流量写入、校准或网络识别。仍按当前网关与设备型号控制 F50 Pro 板块；读取失败、计数缺失、采样缺口或配置错误时不显示可信余量。柱图使用本机每日记录，保留未知与真实零值的区别，不把套餐校准值分配到每日图中。

状态与 NSHostingController 只创建一次。采样更新保留选中日期和展开状态，切换网络时清空旧网络浏览状态。面板宽 390 点、高度按屏幕可用空间限制，内容可滚动；设置、刷新和更多操作固定在底部。真实警告出现在内容顶部。

## 验证结果

- 152 项 Swift 数据回归、118 项原生菜单回归、232 项卡片回归和 10 项脚本检查通过。
- 卡片回归连续 100 次更新，检查原生承载控制器与视图对象稳定、日期选择和详情 / 历史展开状态不丢失。
- 覆盖套餐校准、周期重置标签、配置错误、读取失败与恢复、采样缺口、超过额度、部分计数缺失、同 IP 不同设备、用户别名、切网、零值与未知日期、柱图容量单位和刻度精度。
- 使用生产卡片视图渲染明暗主题、读取失败、普通网络、展开详情及 420 点高度窗口。增加 7 项渲染尺寸检查，总计 239 项卡片及渲染检查通过。
- 修正首次布局中可滚动内容的固有尺寸影响，明确设置面板高度；原生渲染已逐张检查。
- arm64、macOS 12 部署目标构建与签名验证通过；实际安装 0.5.0，进程唯一，版本及 PID 与本地运行快照一致。
- 真实 F50 Pro 只读诊断成功，板块为 ready，月度估算有效，无运行警告。
- 配置完全一致：200 GB、每月 1 日、Asia/Shanghai；逐条核对原网络累计、日记录、月度记录共 10 条，累计未减少，统计起点、名称、校准时间、采样质量及提醒记录保留；月度新增值严格等于设备计数增量，没有重复累加。
