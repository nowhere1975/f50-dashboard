Traffic Monitor — 安装与使用

适用范围

此下载包适用于 Apple Silicon Mac（M 系列芯片），无需 Xcode、Python 或其他依赖。
构建最低目标为 macOS 12；实际验证环境为 macOS 27。旧系统尚待实机验证。
当前路由器模块为中兴 F50 Pro，实机验证固件为 F50ProV1.0.0B27 / MU3356V1.0.0B27。
其他网络也能使用本机实时网速和历史记录；不连接已识别路由器时隐藏路由器板块。

首次安装

1. 打开下载的 DMG 文件。
2. 将 F50Dashboard.app 拖到旁边的 Applications 文件夹。
3. 从「应用程序」打开 F50Dashboard。菜单栏随后出现上传、下载速率。
   程序显示名称为 Traffic Monitor；为兼容已有数据，App 文件名保留 F50Dashboard。
4. 确认菜单栏出现图标后，推出磁盘映像。

首次打开被系统拦截

当前包使用临时签名（ad-hoc），尚未进行 Developer ID 签名和 Apple 公证。
如果提示无法验证开发者，且你确认文件来自本项目的 GitHub Release：

1. 先尝试打开已复制到「应用程序」的 App。
2. 打开「系统设置」→「隐私与安全性」，找到此次拦截记录，选择「仍要打开」。
3. 按照系统提示确认「打开」。

不需要关闭系统安全检查。若提示文件已损坏，先重新下载并核对 SHA-256；
若仍无法打开，请反馈完整提示、芯片型号和 macOS 版本。
Apple 官方说明：https://support.apple.com/zh-cn/102445

开始记录与套餐设置

1. 打开菜单栏的「设置…」，确认本机网卡和路由器模块；一般保持「自动」即可。
2. 使用 F50 Pro 自插卡时，填写自己 SIM 卡的月度套餐额度、重置日和套餐时区。
3. 查询运营商当前周期已用量，填入校准栏后保存。若运营商只显示剩余量，
   用套餐总额减去剩余量，再填写。例如 200 GB 套餐剩余 170 GB，填已用 30 GB。

本机历史从程序开始运行后记录，包含当月全部网络，并区分本机经过 F50 Pro 的用量。
程序未运行时的本机用量无法补回。路由器统计包含其他设备直接连接 F50 Pro 的流量，
但当前不提供每台接入设备的流量明细。套餐余量为校准后的估算，以运营商查询为准。
当前模块只读取设备状态，不要求 root 或 ADB，也不修改路由器配置。

登录时自动启动（可选）

1. 打开「系统设置」→「通用」→「登录项与扩展」。
2. 在「登录时打开」列表点按添加按钮，选择已经安装的 F50Dashboard.app。

此步骤只设置登录时打开，不提供异常退出后的自动重启。
macOS 12 的入口位于「系统偏好设置」→「用户与群组」→「登录项」。
Apple 官方说明：https://support.apple.com/zh-cn/guide/mac-help/mh15189/mac

已有版本升级

1. 在原程序菜单选择「退出」，确保最后一段累计已经保存。
2. 备份下列整个数据文件夹，可在 Finder 的「前往文件夹」中粘贴路径：
   ~/Library/Application Support/F50Dashboard/
3. 用新 App 替换原安装位置的 F50Dashboard.app，然后打开新 App。
   若旧版由 build.sh install 安装，原位置是 ~/Applications/F50Dashboard.app，
   请在这个位置替换；不要再另装一份到 /Applications。

配置、套餐校准和历史仍使用原数据目录，替换 App 不会删除这些数据。
已有 LaunchAgent 的用户继续使用原自启配置，不要重复添加系统登录项。
若仍在使用 0.1.0，请使用仓库 ./build.sh install 的旧版保护流程升级。
请勿在原程序仍运行时强行覆盖 App。

卸载

1. 在程序菜单选择「退出」。
2. 在系统「登录项」中移除自己添加的 F50Dashboard。
3. 将已安装的 F50Dashboard.app 移到废纸篓。

若曾使用 build.sh install，先在仓库运行 ./build.sh uninstall 移除旧 LaunchAgent。
卸载不需要删除数据文件夹；保留数据便于以后恢复。

校验下载文件（可选）

Release 同时提供 .dmg.sha256 文件。将它与 DMG 放在同一文件夹，
在终端进入该文件夹，执行：
shasum -a 256 -c *.dmg.sha256
预期显示文件名及 OK。
