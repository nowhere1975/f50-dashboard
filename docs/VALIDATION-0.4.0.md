# 0.4.0 菜单规划与条件显示验证

日期：2026-10-14。环境：Apple Silicon、macOS 27、F50ProV1.0.0B27 / MU3356V1.0.0B27。

## 实现

主菜单保留实时速率、当前网络和历史入口。当前网关由型号确认为 F50 Pro 后，才显示专属板块；设备原始计数、WAN IP、网关和接入设备地址位于「详细信息」，近七天及各网络累计位于「历史用量」。

型号证明与当前网关响应绑定，并按 MAC 留存。其他网络不显示 F50 Pro 的探测、错误和配额占位行；同一已确认设备临时读取失败保留板块，但不保留旧用量数字。型号明确变为其他设备时撤销旧身份；网络名称、相同网关 IP 或其他地址上的 F50 Pro 响应都不能证明当前网络是 F50 Pro。

## 验证结果

- 152 项 Swift 回归检查、10 项脚本检查通过。
- arm64、macOS 12 部署目标构建与签名验证通过。
- 使用生产菜单构建代码在原生 AppKit 中生成并更新 NSMenu，验证子菜单可用、五个操作入口的目标有效，以及连接、临时失败、家庭网络三种菜单结构。检查在优化模式下使用有效的前置条件断言。
- 实际安装 0.4.0，真实设备诊断通过；本地运行快照显示 F50 Pro 板块为 `ready`，主菜单包含「详细信息」「历史用量」，不直接列出 WAN IP、设备原始计数或全部网络累计。
- 200 GB、每月 1 日、Asia/Shanghai 配置原样保留；所有既有累计、最早统计时间、网络名称、每日记录与套餐校准时间均保留，用量仅接续新增统计。
- 正常停止并重启后，新进程启动快照中 F50 Pro 板块已显示为 `loading`，随后变为 `ready`；确认身份由保存记录接续，月度增加值严格等于设备计数增量，没有重复加旧计数，也没有新增运行提示。

## 覆盖与边界

离线覆盖普通网络、未知设备探测、同 IP 不同 MAC、用户别名、其他 F50 型号、缺失设备列表、跨接口身份、缺失 MAC、断网、失败与重试、迟到响应、其他管理地址、部分计数缺失、身份撤销和子菜单层级。

真实运行与重启验证仅在当前 F50 Pro 网络完成，未主动切换用户的物理网络。原生菜单结构验证不等于完整鼠标点击验收；通知送达、其他固件、Intel 和旧 macOS 实机仍未验证。套餐余量仍为校准后的估算，以运营商查询结果为准。
