# Traffic Monitor

macOS 菜单栏流量看板，提供本机实时网速、月度历史和可扩展路由器统计。版本：0.8.0。当前内置 F50 Pro 适配模块。

## 下载安装

[下载 Apple Silicon 安装包（DMG）](https://github.com/nowhere1975/f50-dashboard/releases/latest) · [安装、升级和卸载说明](docs/INSTALL.txt)

打开 DMG，将 `F50Dashboard.app` 拖入「应用程序」后打开，无需开发工具。当前包尚未做 Developer ID 签名和 Apple 公证；若系统拦截，请按安装说明通过「隐私与安全性」确认打开。

适合使用 Mac 和自插卡 F50 Pro 的用户试用，也能单独监控其他网络的本机网速。当前下载包为 Apple Silicon 版，实测 macOS 27、F50 Pro B27 固件；旧系统及其他固件欢迎反馈兼容情况。反馈时请附 macOS 版本、芯片、固件和 USB/Wi-Fi 连接方式。

点击菜单栏打开原生菜单。菜单上方嵌入透明信息卡片，显示实时速率、当前网络、已支持路由器的 SIM 卡套餐进度条和本机月度用量方块图；下方是带右箭头的「详细信息」「历史用量」子菜单，以及设置、刷新等普通菜单项。

## 菜单显示规则

| 板块 | 显示内容与条件 |
|---|---|
| 实时速率 | 始终显示，本机当前接口的上传、下载速率 |
| 当前网络 | 主行显示「网卡名 · 本机 IPv4」，下一行以小字号、次要颜色显示网关 IP；保留本网络累计，悬停地址可查看网络名称 |
| 路由器 | 当前网关经已选模块确认后显示；套餐、信号和接入设备分别按模块能力显示，其他网络隐藏 |
| 详细信息 | 仅在已确认的路由器网络显示，原生子菜单包含型号、固件、原始计数、WAN IP、网关和设备地址 |
| 本机月度用量与历史 | 按当月实际天数显示方块，汇总所有网络的本机用量并区分已确认路由器；历史子菜单保留当前网络近七天明细、各网络累计和系统网卡累计 |

采用与 CodexBar 相同的原生菜单承载方式（`NSMenuItem.view`），卡片没有内部滚动区和实色底板，背景、圆角和投影由 macOS 菜单负责。明暗主题和「减少透明度」设置会影响实际材质；屏幕高度不足时由原生菜单显示上下滚动箭头。

连续刷新复用菜单项、子菜单及卡片视图，展开期间保持行高，避免打断浏览；菜单结构和高度在下次打开时更新。历史只有一种模块时使用其名称（例如 F50 Pro），有多种模块时合并显示「路由器」。月度图以强调色表示当天存在本机路由器用量，灰色表示已记录但没有路由器用量（含真实零值），空心表示未记录，未来日期使用更淡的空心方块。悬停时浮出日期和本机总量；有路由器用量时同时显示其中路由器与其他网络用量，移开后隐藏，不占用固定行高。卡片不常驻显示每日明细、已记录天数或套餐说明，套餐用量统一标为「本月用量」。

设备身份由当前网关的型号响应和模块确认，并按网关 MAC 留存。网络名称或相同网关 IP 不能证明设备型号。仍连接已确认设备时，临时读取失败保留板块并清空旧余量；切网关闭旧菜单。MAC 不可用时，身份只在当前网络会话有效。

自定义管理地址须使用当前网关 IP（可带端口）才能参与板块显示和套餐统计；其他地址、主机名仍可用 `--check` 诊断。

## 流量口径

- **本机用量**：当前网卡的字节增量，仅覆盖 App 运行且采样有效的时段。月度图按本机日历月汇总所有网络，展示本月总量、其中路由器、其他网络；均为上传与下载之和，不包含其他设备直接连接路由器的流量。
- **历史归属**：路由器分类依据曾经验证过的设备型号与网关 MAC，不依据用户自定义名称。已确认的网络归属单独持久保存；当前设备信息移除不改变既有历史分类。旧版记录从已有型号确认信息补齐归属，原日记录和累计不变。
- **月度记录范围**：未采集的日期不补成零，未来日期不计入汇总；没有记录的月份显示「—」。每日历史长期保存，七天或当月仅为展示范围。记录开始前的用量无法补回，页面标注当月已记录天数。
- **设备原始统计**：已支持路由器「详细信息」中的管理接口累计值，只统计经过设备的数据，不提供 SIM 卡的套餐总额或运营商余量。实测统计值可在月内下降。固件字段名包含 `monthly`，仍不能直接视为完整套餐月度用量。
- **SIM 卡套餐额度**：由用户根据自己插入的卡填写，程序不自动查询运营商账户。
- **套餐周期**：按用户填写的每月重置日和套餐时区计算，界面显示起止日期；29–31 日遇短月份取该月最后一天，后续月份仍按原重置日计算。
- **月度已记录**：保存设备上传、下载计数的增量；首次读数只建基线，不把未知的历史用量算入本月。设备清零后继续累积，跨月建立独立记录，保留以前周期。
- **月度估算与剩余**：在设置中填写运营商当前「本周期已用量」后，接续设备增量并估算百分比和余量。初始用量未知、字段来源变化、设备清零或断采超过 `max(120, routerPollSec × 3)` 秒时，可能漏记，暂停百分比、余量和配额提醒，等待再次校准。实际套餐余量以运营商查询结果为准。
- 所有容量使用十进制单位：1 GB = 10⁹ B。
- 日用量按本机时区归集；跨午夜的一个短窗口记入采样结束日。未记录的日期显示「—」，不会补成零。
- 切网、换网卡、计数重置、读取失败、休眠或过长采样间隔后重建基线，不回填不确定窗口。

## 构建与安装

需要 Xcode Command Line Tools 和 Python 3，不下载第三方依赖。

~~~bash
./build.sh test       # 离线回归检查
./build.sh            # 构建当前机器架构，显式指定 macOS 12 部署目标
./build.sh install    # 备份旧 App、配置和累计，安装并启动
./build.sh package    # 重新构建，生成并验证 Apple Silicon DMG 和 SHA-256
./build.sh check      # 检查本机采样和路由器只读接口
./build.sh uninstall  # 移除开机自启，将 App 留存在数据目录
~~~

从 0.1 升级前，在旧版菜单点击一次「退出」，确保内存累计写入 `state.json`。旧版可能自动拉起，安装程序会停止旧服务后替换 App。升级备份位于数据目录的 `upgrades/`。

0.2 正常退出后不自动重启，异常退出由 LaunchAgent 尝试恢复。文件锁阻止多个 App 实例同时写入。

构建目标为 macOS 12+，实际验证环境为 Apple Silicon、macOS 27、Swift 6.4。旧系统与 Intel 运行仍需实机验证。本机 CLT 缺少 Intel 兼容库，Intel 交叉构建未完成。

## 配置与设置

菜单选择「设置…」，保存后立即生效；也可编辑：

~~~text
~/Library/Application Support/F50Dashboard/config.json
~~~

~~~json
{
  "quotaGB": 100,
  "billingTimeZone": "Asia/Shanghai",
  "routerGateway": "auto",
  "routerAdapter": "auto",
  "interface": "auto",
  "localPollSec": 2,
  "routerPollSec": 30,
  "showRateInTitle": true,
  "networkNames": {},
  "enableQuotaAlerts": false
}
~~~

| 配置 | 含义与范围 |
|---|---|
| `quotaGB` | 月度套餐额度，大于 0，且不超过 1000000 GB |
| `billingCycleDay` | 套餐每月重置日，1–31；默认未设置，不根据设备清零日猜套餐周期 |
| `billingTimeZone` | 套餐时区，默认 `Asia/Shanghai`；与本机每日用量的时区分别计算 |
| `routerAdapter` | `auto` 自动识别、`none` 不读取路由器，或指定内置模块 ID；当前为 `zte.f50pro` |
| `routerGateway` | `auto` 使用当前 IPv4 网关；可指定 IP 或主机名，可带端口 |
| `interface` | `auto` 使用系统主接口；可指定网卡，如 `en0` |
| `localPollSec` | 本机采样间隔，1–60 秒 |
| `routerPollSec` | 路由器采样间隔，5–3600 秒 |
| `showRateInTitle` | 菜单栏显示速率或当前网络累计下载量 |
| `networkNames` | 网络标识到显示名称的映射，可在设置界面修改 |
| `enableQuotaAlerts` | 默认关闭；在设置界面开启后请求系统通知权限 |

外部改配置后，下次打开菜单时重新加载并更新定时器。格式、类型或范围错误时，保留原文件与当前有效配置并提示，不覆盖为默认文件。配置加载错误未解决时暂停额度估算，避免默认额度被误当成真实套餐。

首次设置时填写重置日（例如每月 1 日），并查询运营商当前本周期已用量后校准。校准需连接可识别网关 MAC 且支持累计流量的路由器，设备读数须足够新；修改网卡或管理地址时先另行保存、刷新。校准不会修改路由器配置，也不会替换本机累计。历史 CSV 与本机记录无法补齐所有接入设备的整月用量，因此不会自动导入为套餐月度基准。

提醒按 80%、90%、100% 触发，同一套餐周期不重复；设备清零和同周期校准不重置提醒。新周期先记录观察到的增量，初始用量确认前不估算完整月度余量。提醒依据校准后的估算，不代表运营商通知。

## 网络识别与保存

通过 SystemConfiguration 读取主网卡、网关、DNS 和可用的网关 MAC，不读取 SSID、不申请位置权限。优先按 MAC 分桶；MAC 不可用时退回网卡、网关和 DNS，相同配置仍可能合并。

App 的路由器响应必须绑定当前网络、当前网关和适配模块，并由型号字段确认。切网清空快照，迟到的响应被丢弃。零用量有效；计数缺失、无效或只有单边计数时不估算余量。缺少接入设备列表时显示未知，不补成零台。

接口累计采用本机已交叉验证的 `netstat -ibn` 来源，在串行后台线程读取，不阻塞菜单；进程超过 2 秒时终止并视为失败。本机系统原生计数在第三方进程中与 `netstat` 不一致，因此未采用该读数。

每 30 秒原子保存累计，保留上一份有效 `state.backup.json`。加载失败时先留存损坏文件，再尝试恢复备份并提示。异常退出最多丢失上次成功保存后的有效采样；写入失败时显示提示。

同一台已确认的 F50 Pro 在升级前后的累计会合并，界面只显示一条「F50 Pro」。合并保留上传、下载总数和最早统计时间，并转移已有日记录，不反推缺失的每日历史。合并前独立备份原记录为 `state.before-f50-merge.<UUID>.json`，不会被定时备份轮换覆盖。存在多台已确认 F50 时不猜归属。

## 诊断与数据

~~~bash
~/Applications/F50Dashboard.app/Contents/MacOS/F50Dashboard --check
~~~

检查配置、网络、计数与路由器接口；没有识别到支持累计流量的路由器或数据无效时返回非零，不表示 App 无法启动。

~~~text
~/Library/Application Support/F50Dashboard/
  config.json
  state.json
  state.backup.json
  state.before-f50-merge.<UUID>.json
  runtime.json
  app.stdout.log
  app.stderr.log
  upgrades/
~~~

`runtime.json` 是本地运行快照，包含版本、进程、网络标识、刷新间隔、保存状态、路由器模块 ID 与板块状态和主菜单标题。诊断输出可能包含本地网络标识，分享前可按需要遮盖。

## 可选 CSV 脚本

~~~bash
tools/router-traffic.sh status
tools/router-traffic.sh watch
tools/router-traffic.sh report
tools/ssid-traffic.sh sample
tools/ssid-traffic.sh report
~~~

- 路由器脚本只读，不登录、不保存密码或 Cookie。每分钟调用 `watch` 时默认每五分钟采样；检查不更新实际采样时间。
- `ssid-traffic.sh` 保留历史命名，实际按网关 MAC/IP 区分，不读取 SSID。切网和长间隔重建基线。
- 默认输出到 `~/inbox/`。可用 `RT_CSV`、`RT_STATE`、`RT_GATEWAY`、`RT_SAMPLE_SEC` 或 `SSID_TRAFFIC_CSV`、`SSID_TRAFFIC_STATE` 覆盖路径和采样参数。
- 响应文本通过 Python `csv` 模块写入，不作为 shell 代码执行。
- 报告在断线、恢复和计数下降后重建基线。路由器覆盖全部设备，本机读数只覆盖当前接口。
